# Data-Driven Evaluation and Generalizability of Metamorphic Geothermobarometers

This repository contains the reproducible data-science workflow associated with
the project based on:

Rabbani, H. & Wu, C.-M. (2026).
Applicability of geothermobarometers in the metamorphic mineral assemblage
plagioclase + hornblende + quartz ± garnet.
Journal of Asian Earth Sciences, 306, 107096.

DOI: 10.1016/j.jseaes.2026.107096

## Repository structure

- `data/raw/` — frozen author-supplied supplementary datasets
- `data/processed/` — processed analytical datasets
- `scripts/` — reproducible Python analysis scripts
- `results/` — tabular audit and statistical outputs
- `figures/` — generated figures
- `metadata/` — provenance, hashes, data dictionary, AI-use log
- `reports/` — assignment reports
- `notebooks/` — executable assignment notebooks

## Current scope

Assignment 1 focuses on data provenance, measurement integrity,
schema validation, missingness, duplicate handling, anomaly screening,
calibration-domain checks, and leakage prevention.
